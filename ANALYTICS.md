# Portfolio analytics

The site uses [GoatCounter](https://www.goatcounter.com/) for minimal,
privacy-friendly analytics. Tracking is invisible to visitors and records page
views, page paths, referrers, and campaign attribution without adding cookies.

Dashboard: <https://ftaiuti.goatcounter.com/>

## Campaign links

Keep UTM names lowercase and reuse the following links consistently:

- LinkedIn profile and posts:
  <https://filippotaiuti.dev/?utm_source=linkedin&utm_campaign=portfolio>
- Curriculum vitae:
  <https://filippotaiuti.dev/?utm_source=cv&utm_campaign=portfolio>

`utm_source` distinguishes the channel. `utm_campaign=portfolio` groups both
links into the same long-running portfolio campaign.

GoatCounter creates campaign entries automatically when visits arrive through
these URLs. Do not put personal data in UTM values.

## Verification

Open a campaign link in a browser where analytics blocking is disabled, then
check the GoatCounter dashboard after a few seconds. The visit should appear
under the `portfolio` campaign with the expected source.
